# FocusMate — 讀書專注計時與學習紀錄

一個以 HTML、CSS 與 JavaScript 製作的互動式讀書專注工具，協助大學生安排專注時間、追蹤學習紀錄，並掌握每日學習成果。

## 🌐 線上體驗

**GitHub Pages：** [點此開啟 FocusMate](https://iamstudent578.github.io/focusmate-study-timer/)

## 📌 專案簡介

FocusMate 以大學生的讀書與課業需求為出發點，提供簡單直覺的專注計時及學習紀錄管理功能。

使用者可以設定科目與專注時間，在完成一段專注時段後，由系統自動新增學習紀錄並更新今日統計，減少手動記錄學習時間的負擔。

## ✨ 主要功能

### 1. 專注倒數計時
- 預設專注時間為 25 分鐘，並提供快捷選項及自訂時間。
- 支援開始、暫停、繼續及重設。
- 計時完成時顯示完成提示。

### 2. 計時器狀態與進度顯示
- 顯示準備開始、專注中、已暫停及本次完成等狀態。
- 透過圓形進度環呈現實際計時進度。
- 改善計時器與完成提示的版面配置，避免介面元素重疊。

### 3. 科目設定
- 可輸入科目名稱或學習項目。
- 對空白科目及無效時間提供輸入驗證。
- 計時進行中限制修改科目與時間。

### 4. 學習紀錄管理
- 計時正常完成後，自動新增一筆學習紀錄。
- 記錄科目、完成日期與時間，以及專注分鐘數。
- 最新紀錄顯示在最上方。
- 支援刪除單筆紀錄，並在刪除前要求確認。

### 5. 今日學習統計
- 顯示今日完成的專注時段數。
- 顯示今日累積專注分鐘數。
- 新增或刪除紀錄後同步更新統計。

### 6. 資料保存與響應式介面
- 使用瀏覽器 `localStorage` 保存完成紀錄。
- 重新整理後可讀取已保存的紀錄。
- 支援電腦及手機瀏覽器操作。

## 🛠️ 使用技術

- **HTML：** 建立網頁結構。
- **CSS：** 設計介面、計時器視覺效果與響應式版面。
- **JavaScript：** 實作倒數計時、狀態切換、紀錄管理及統計更新。
- **localStorage：** 保存瀏覽器中的學習紀錄。
- **GitHub Pages：** 公開部署網站。

本專案將 HTML、CSS 與 JavaScript 整合在單一 `index.html` 檔案中，不需要另外啟動後端服務或資料庫。

## 🚀 如何使用

### 線上使用
1. 開啟上方的 GitHub Pages 網站。
2. 輸入科目名稱並設定專注時間。
3. 按下開始，依需求暫停、繼續或重設。
4. 完成專注時段後，查看自動新增的學習紀錄。
5. 透過今日統計了解完成次數與累積專注時間。
6. 必要時可以刪除不需要保留的學習紀錄。

### 在本機執行
1. 下載或複製 Repository 中的 `index.html`。
2. 使用瀏覽器開啟該檔案。
3. 即可操作主要功能，不需要額外安裝套件。

## 💾 資料保存說明

學習紀錄儲存在目前瀏覽器的 `localStorage` 中。

- 重新整理同一網站時，已保存的紀錄仍可讀取。
- 本機直接開啟的 HTML 與 GitHub Pages 網站屬於不同的來源，兩者的資料不會自動共用。
- 不同瀏覽器或裝置之間不會自動同步資料。
- 清除瀏覽器的網站資料可能導致已保存的紀錄遺失。

## 🔄 AI 協作與迭代開發

本專案透過 AI 輔助需求規劃、網頁實作、問題分析及功能優化，並依據實際操作結果進行分階段修改。

### 第一階段：需求規劃與初版實作
與 AI 討論使用情境，整理計時器、科目設定、學習紀錄、每日統計、資料保存及響應式版面的功能規格，再依照規格完成第一版。

### 第二階段：計時器互動回饋優化
請 AI 加入計時狀態提示與圓形進度環。實際操作後發現進度環及完成提示出現版面重疊，因此再次要求 AI 檢查 HTML 與 CSS，針對容器尺寸、間距及響應式樣式進行修正。

### 第三階段：學習紀錄管理優化
請 AI 新增單筆紀錄刪除與確認機制，並確保刪除後的今日統計及 `localStorage` 資料能同步更新。

### 第四階段：測試與問題修正
透過實際操作檢查計時、輸入驗證、資料保存、統計更新及手機版排版，並在發現問題時，向 AI 提供具體的操作步驟、實際結果與預期結果，以利針對性修正。

## ✅ 測試紀錄

第一版曾進行以下八項手動測試，回報結果均為通過：

- 計時完成是否重複新增紀錄。
- 暫停、繼續與重設的狀態。
- 快速操作造成的重複執行。
- 資料保存與統計一致性。
- 無效輸入與邊界值。
- 計時中的科目與時間修改限制。
- 空紀錄、多筆紀錄與統計排列。
- 手機版版面。

後續針對計時器介面及學習紀錄管理進行兩輪優化。最終版本仍應以優化後的回歸測試及 GitHub Pages 公開網站驗收結果為準。

## 📄 專案限制

- 目前以單一使用者的本機學習紀錄為主。
- 不提供帳號登入、雲端同步或跨裝置資料共享。
- 未完成的計時器不會在重新整理後自動恢復。
- 網站不依賴後端服務。
